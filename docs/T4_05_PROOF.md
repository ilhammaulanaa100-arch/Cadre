# T4-05 — local compute benchmark and worker sizing

30 September 2026. Ini baseline **lokal**, bukan hasil VM produksi. Host: MacBook Pro Apple M2, 8 core, RAM 8 GB; Node 26.0.0; Chrome 154.0.8037.92. Next production build disajikan di loopback, setiap job membuka proses/profil Chromium baru, PNG 1200 × 1200. Data mentah: [default GPU](evidence/t4-05/benchmark-local.json) dan [SwiftShader software](evidence/t4-05/benchmark-swiftshader.json). Ulangi dengan `node scripts/benchmark-local-worker.mjs`, atau `FORMA_RENDER_BACKEND=swiftshader FORMA_BENCHMARK_REPEATS=3 FORMA_BENCHMARK_PAIRS=2 node scripts/benchmark-local-worker.mjs` saat server internal lokal aktif.

| Jalur | Sampel | Waktu total Single median | Duo median | Puncak RSS gabungan proses satu job | Dua job paralel |
|---|---:|---:|---:|---:|---|
| Chrome default pada M2 | 5 + 5, 3 pasang | 1.89 detik | 1.60 detik | 1.21–1.39 GiB | 1.97–2.61 detik per job; RSS 2.33–2.59 GiB |
| SwiftShader, tanpa GPU fisik | 3 + 3, 2 pasang | 11.81 detik | 11.79 detik | 1.35–1.62 GiB | 14.25–15.76 detik per job; RSS 2.68–2.71 GiB |

Chrome benar-benar melaporkan `SwiftShader Device` pada jalur software. Pada jalur ini median tahap capture sekitar 6 detik; CPU time teramati sekitar 33–36 detik untuk satu job. Dua job paralel memakai sekitar 62 detik CPU total dan saling memperlambat. [PNG software Single](evidence/t4-05/software-single.png) dan [PNG default](evidence/t4-03/single.png) berukuran sama; perbedaan RGB rata-rata 0.099/255 dan keduanya telah diperiksa visual.

**Keputusan awal untuk staging:** target VM **4 vCPU / 8 GiB RAM**, satu slot render aktif per VM. Dua slot terlihat muat pada Mac 8 GB, tetapi RSS gabungan 2.7 GiB belum mencakup sistem operasi, server web, dan margin lonjakan upload. Naikkan ke dua slot hanya setelah uji pada VM Linux pilihan membuktikan puncak memori, waktu tunggu, dan stabilitas. Batasi pekerjaan dalam antrean, satu Chrome per slot, serta timeout; jangan menyimpulkan kapasitas publik dari 8 sampel software di Mac. `ps` menjumlah RSS banyak proses Chrome sehingga halaman memori bersama bisa terhitung lebih dari sekali; waktu CPU sampling juga merupakan pendekatan, bukan profiler penuh.

**Perkiraan uang untuk kelas VM tersebut, hanya worker:** harga DigitalOcean Basic 4 vCPU/8 GiB saat dicek 30 September 2026 adalah **US$48/bulan**; CPU-Optimized 4 vCPU/8 GiB adalah **US$84/bulan** ([harga resmi](https://www.digitalocean.com/pricing/droplets)). Bila satu VM hidup terus, alokasi biaya fixed worker menjadi sekitar US$0.48–0.84 per PNG pada 100 export/bulan, US$0.048–0.084 pada 1.000, atau US$0.0048–0.0084 pada 10.000. Itu pembagian biaya VM, **bukan** harga marginal proses render; belum termasuk web/API, database/auth, storage, bandwidth, pajak, dan tenaga pemeliharaan. Sebagai acuan terpisah, Supabase Pro saat dicek berharga US$25/bulan untuk satu project Micro dalam kredit compute yang disertakan ([harga resmi](https://supabase.com/pricing)). Tidak ada pembelian atau deployment.

**Gerbang yang masih terbuka:** jalankan build yang sama di VM Linux 4 vCPU/8 GiB dengan versi Chromium yang dipin, uji 1 dan 2 slot, output visual, p95 antrean/render, 100+ job beruntun, kegagalan Chrome, dan biaya aktual. Jalur SwiftShader memakai flag eksplisit `--enable-unsafe-swiftshader`; [dokumentasi Chromium](https://chromium.googlesource.com/chromium/src/+/main/docs/gpu/swiftshader.md) menyatakan jaminan keamanannya lebih rendah. Worker produksi harus membatasi input dan jaringan serta mengisolasi proses/job sebelum jalur ini dipakai untuk upload pengguna.
