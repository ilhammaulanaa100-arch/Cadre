# T4-04 — proxy/full alignment and canonical image proof

30 September 2026. Preview iPhone memakai `iphone-18-pro-max-proxy.glb` (3,051,052 byte), diturunkan dari model penuh (4,442,824 byte). Proxy lebih kecil 31.3% karena tekstur normal dan contoh screenshot tertanam dihapus. Geometri, node, transform, UV, material slot dan semua 260 accessor tetap; layar selalu diganti oleh screenshot scene. `node scripts/check-proxy-asset.mjs` membandingkan metadata dan byte accessor kedua GLB, memastikan hash pin, serta memastikan model penuh tidak tersalin ke folder `public`.

Editor dan render surface sekarang memakai `createScreenCanvas` yang sama untuk Fit, Fill, crop dan padding. Upload PNG/JPEG/WebP dinormalisasi melalui decoder browser menjadi PNG sRGB; orientasi EXIF diterapkan sebelum file disimpan dalam draft. Worker menormalisasi sumber melalui fungsi yang sama. Release `0.4.0`, color pipeline dan SHA-256 aset tercatat di `packages/catalog/src/render-release.json`. Worker menolak release, versi device, atau byte aset yang berbeda dari pin; render surface memeriksa release dan hash lagi sebelum memuat scene. Model penuh hanya dilayani oleh route render internal saat mode proof lokal diaktifkan. Ini belum menjadi mekanisme storage privat produksi.

Uji produksi lokal `node scripts/check-render-alignment.mjs` mengambil PNG editor dari profil Chrome baru, membaca snapshot scene yang tersimpan, lalu meminta worker merender snapshot yang persis sama. Hasil [preview proxy](evidence/t4-04/preview-proxy.png) dan [render full](evidence/t4-04/render-full.png) sama-sama 1200 × 1200; inspeksi visual menunjukkan framing/crop identik. Perbandingan RGB oleh `python3 scripts/check-render-alignment.py` memberi rata-rata selisih absolut **0.1496/255** per kanal. Selisih kecil berasal dari normal texture yang hanya ada pada model penuh.

Kasus kedua mengunggah [JPEG dengan EXIF orientation 6](evidence/t4-04/orientation-source.jpg). [PNG canonical](evidence/t4-04/orientation-canonical.png) berukuran 320 × 180 (sumber mentah 180 × 320), tanpa tag orientasi; empat warna sudut diperiksa. [Preview](evidence/t4-04/orientation-preview.png) dan [render](evidence/t4-04/orientation-render.png) tetap mempunyai selisih rata-rata 0.1496/255. Regresi Duo, 23 unit test, typecheck dan build lulus.

Batas: hasil warna lintas GPU/browser lain belum dijamin pixel-identik; proof ini memakai Chromium lokal yang sama. Tablet/laptop masih fixture dengan asset preview dan render yang sama; model final dan pasangan proxy/full tiap katalog diuji di tahap 6. Queue, auth dan storage privat tahap 5 belum ada. T4-05 berikutnya mengukur kebutuhan compute worker.
