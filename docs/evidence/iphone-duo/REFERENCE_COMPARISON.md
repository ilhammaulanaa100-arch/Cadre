# Duo asset provenance and visual tradeoffs

9 October 2026. The public product viewer was used as a visual reference, but the current model is generated from project-authored Blender geometry and morph animation. The previous viewer-derived model was replaced before the first public push.

The procedural model preserves the mockup workflow: one foldable device, independent outer and inner screen images, a connected inner display, fold slider, opening playback, and selected-frame PNG. It uses the fictional dashboard fixture for starter screens and Blender's own lighting for renders. No downloaded viewer mesh, texture, rig, or environment map is a runtime dependency.

Visual fidelity is lower than the earlier viewer-derived adaptation. The camera optics, chassis details, metal reflections, and fold mechanics are approximations. This asset is for screen-design mockups, not a pixel-matched product rendering or engineering model.
