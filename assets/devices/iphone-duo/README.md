# iPhone Duo mockup asset

Updated 9 October 2026. This is a project-authored procedural foldable mockup, generated by `scripts/generate-iphone-duo.py` in Blender 5.2. It replaces the earlier asset adapted from a public product viewer. The current generator does not load downloaded viewer geometry, textures, UVs, environment maps, or animation data.

## Files and provenance

- `iphone-duo.blend`: editable Blender scene generated from meshes, primitives, materials, and morph targets defined in the project script.
- `iphone-duo.glb`: web model with one fold animation. `asset-info.json` records its size and SHA-256.
- `textures/reference-outer.png` and `textures/reference-inner.png`: copies of the project's fictional dashboard fixture, used as replaceable starter screens. They are not product viewer screenshots.
- `renders/` and `previews/`: outputs of the project-authored Blender scene.

The prior raw viewer downloads remain only in the ignored local `reference-source/` folder and are not needed to regenerate this asset. Do not add that folder to a public repository.

## Renderer contract

`ScreenOuter` is the independently editable exterior display. `ScreenInner` is one connected, UV-mapped inner mesh with two authored morph targets. The `Scene` animation drives the left chassis and inner-screen morphs from closed (frame 1), through half-open (frame 24), to open (frame 48). Forma samples this animation deterministically for the fold slider and exported PNG. Its browser shader adds blur/dimming during the fold. Material variants use the project's neutral Star White base and Night Sky recoloring.

The geometry is a visual mockup, not manufacturer CAD or an exact replica. Its dimensions, camera deck, hinge, and reflection response are project estimates. The earlier 27-joint source rig and viewer-derived environment map are no longer used.

## Regenerate

```sh
/Applications/Blender.app/Contents/MacOS/Blender -b --python scripts/generate-iphone-duo.py
node scripts/sync-fixtures.mjs
```

`-- --no-renders` regenerates the Blender source and GLB without proof images. The fixture sync copies only runtime assets to the web apps and clears older Duo copies first.
